# 📖 About

**DevClash 2026** is the official website for **DevClash**, a national-level 24-hour hackathon organized by **DevKraft**.

The platform was designed to provide participants with a smooth and engaging experience—from learning about the event and registering, to exploring schedules, prizes, sponsors, FAQs, and important announcements.

Built with performance and user experience in mind, the website combines modern web technologies with clean design and responsive layouts.

# 🚀 Getting Started

## Clone the repository

```bash
git clone https://github.com/parthsawang/devclash-2026.git
```

## Navigate into the project

```bash
cd devclash-2026
```

## Install dependencies

```bash
npm install
```

## Start development server

```bash
npm run dev
```

Visit

```
http://localhost:5173
```

---

# 📦 Production Build

Build the project

```bash
npm run build
```

Preview the production build

```bash
npm run preview
```
